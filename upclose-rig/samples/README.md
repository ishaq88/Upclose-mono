# Real engine clips (calibration samples)

Openly licensed recordings of real engines, for calibrating the audio features. The audio files are git-ignored; download them again from the URLs below and compare the sha256.

The license of each clip was read on its Wikimedia Commons file page. Neither the pages nor the descriptions say that any clip is an idle recording, so treat them as "engine running" clips, not confirmed idle.

All three are **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/): credit the author, link the license, and say if you changed the file. A clip is used as real recorded audio; label anything derived from it accordingly and never as the output of the simulator.
